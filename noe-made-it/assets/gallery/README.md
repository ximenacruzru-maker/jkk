# Gallery photos

Upload your photos into this folder using exactly these names (they're what `gallery.html` looks for):

| Photo | File name |
| --- | --- |
| Kraft box with the red foam finger ("Emiliano") | `gable-box-foam-finger.jpg` |
| "The MVP Turns 10" stadium box | `gable-box-mvp.jpg` |
| Blue "30" balloon cake topper | `cake-topper-30.jpg` |
| "It's Fun to Be One" hippo cake topper | `cake-topper-fun-to-be-one.jpg` |

Until a photo is uploaded, the gallery shows a colored placeholder for it.
To add more pieces, add a photo here and copy one of the blocks in the `pieces` list in `gallery.html`.
